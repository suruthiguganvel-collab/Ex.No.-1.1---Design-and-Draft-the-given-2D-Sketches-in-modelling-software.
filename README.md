# Ex.No.-1.1-Design and Draft the given 2D Sketches in modelling software.

## AIM

To sketch the given drawing with dimensions using fusion 360 tool.

## REQUIREMENTS

  1. Autodesk fusion 360
  2. Windows 10
  3. 16 GB of RAM (integrated graphics recommend 2 GB or more)
  4. 2.5 Mbps or faster download; 500 Kbps or faster upload 
  
## PROCEDURE

1.	Create a New File and Initialize Sketch:

     1.Open the CAD modeling software(such as Fusion 360).
  	 2.Click on the 'NEW DESIGN' or 'NEW FILE' option to start a fresh workspace.
  	 3.Navigate to the tool menu and click on the 'Create Sketch'.
  	
2.	Select the Datum Working Plane:

      1.Identify the primary reference planes (XY, YZ, OR XZ plane).
  	  2.Choose and select the required standard plane(e.g., Top, Front, or Right plane)based on the drawing requirement to start sketching.
  	
3.	Draw The Basic 2D Geometry Using Sketching Tools:

      1.Select suitable sketching features such as Line, Circle, Arc, Rectangle, Polygon, or Spline from the toolbar.
  	  2.Draw the initial profile according to the shape and baseline requirements of the given 2D diagram.

4.	Edit And Modify The Geometry Using Editing Tools:

      1.Utilize sketch modification tools like Trim, Extend, Cut, Mirror, Offset, Fillet, Chamfer, or Move to refine the profile.
  	  2.Remove extra line and accurately construct complex shapes as per the given design.

5.	Inspect And Dimension The Sketch:

       1.Apply geometric constraints(e.g., Horizontal, Vertical, Tangent, Coincident) to constrain the geometry.
  	   2.Use the 'Inspect'/'Dimension' tool to measure and define exact dimensional values(length, radius, diameter, angle)for each entity to ensure accuracy.

6.	Finalize The 2D Sketch:

        1.Recheck all dimensions, constraints, and geometry for completeness.
  	    2.Click on the 'Finish Sketch' option on the top right toolbar to exit the sketch environment and finalize the 2D profile.

7.  Generate The Technical Drawing Sheet(Drafting in ISO Standard):

         1.Switch from the modeling workspace to the drawing mode(e.g., Drawing from Design).
         2.Select an appropriate ISO standard drawing sheet template and title block.
         3.Insert the primary orthographic views9Front, Top, Side)and apply proper ISO standard dimensioning, annotations, and title block details to plot the drawing.

PROCESS:
Create new sketch: Open fusion 360,start a new design, click create sketch, and select your preferred working plane.
Draw center circles: Locate the origin point and draw the central inner and outer reference circles.
Create center spline profile: Draw the internal spline/gear profile at the center and use the circular pattern tool to replicate it evenly around the middle.
Positions right-side circles: Place a point along the horizontal axis to the right and draw the corresponding inner and outer circles.
Position left-side circles: Place a point on the left side along the centerline to create the middle inner and outer circles.
Draw complete top-half sketch: Draw the top-left side circles along with all the top connecting arcs, and apply tangent constraints for smooth transitions.
Select mirror tool: Go to create>mirror and select all the top-half circles and arcs and as your objects.
Select center mirror line: Click on mirror line in the dialog box and select the central horizontal centerline to flip the entire top half directly to the bottom half.
Trim unwanted lines: Use the trim tool(T) to clear out any overlapping internal lines and create a clean closed profile.
Finish sketch and extrude: Click finish sketch, select the extrude tool, and apply thickness to convert the sketch into 3D solid model.
